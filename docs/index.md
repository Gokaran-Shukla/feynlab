# feynlab

Feynman diagrams, quantum Monte Carlo, many-body self-energies and anomalous / spin / orbital Hall transport in
one validated Python package. It is a companion to R. D. Mattuck, *A Guide to Feynman Diagrams in the Many-Body Problem*.

* **Software tutorials** 01–14: from getting started to CT-HYB, DFT+DMFT, NRG, analytic continuation, CDet and
  advanced orbitronics transport.
* **Book tutorials**: one per chapter of Mattuck.
* **Slides**: [feynlab_slides.pdf](slides/feynlab_slides.pdf).
* **Quizzes**: `quizzes/quiz.html` (36 quizzes, 187 questions).
* **Benchmarks**: `benchmarks/RESULTS.md` and `benchmarks/RESULTS_v1.md`.
